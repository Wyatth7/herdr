# Plugins

This is a directory containing all of the plugins I find useful to share between machines. Most of these 
plugins are created to support my personal opinions and workflows, so your mileage may vary.

## Installing Plugins

There are a couple way to install and link plugins to your Herdr instance. I prefer using the Herdr marketplace 
installs (GitHub repo), so that is what will be provided when viewing the documentation in this repo.

All plugins can be installed with the following commands.

```bash
herdr plugins install Wyatth7/herdr/plugins/[/path/to/plugin/dir]
```

Specific install instructions can be found at each plugin directory.
